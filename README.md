# Logix Remote

A network adapter for developing on FPGA boards anywhere.

**Coming Q1 2027.** This repository is a placeholder; the work hasn't started here yet. See the [Logix Remote page](https://www.openlogix.org/remote/) for what's planned.

Logix Remote is part of [Open Logix](https://www.openlogix.org/): free, open source tools for FPGA design that install in one step, run on macOS, Windows and Linux, and need no separate toolchain.
